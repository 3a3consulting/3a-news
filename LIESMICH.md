# Firmenlogos für „Meine Unternehmen“

Ohne Logo zeigt das Dashboard Initialen (z. B. „MR“ für Munich Re).

Logo ergänzen (nur mit Freigabe, keine fremden Server):
1. Datei als PNG, quadratisch, ca. 128 × 128 px, Dateiname = Unternehmens-ID aus `unternehmen.json`, z. B. `allianz.png`, `munich-re.png`.
2. Datei in diesen Ordner `logos/` hochladen.
3. In `logos/index.json` die ID ergänzen, z. B. `{"logos":["allianz","munich-re"]}`.
